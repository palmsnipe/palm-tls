PalmTLS 0.1.7

## Changes

- The ARM Browser profile negotiates TLS 1.2 or 1.3 and adds support for
  P-384, SHA-384, RSA-4096, and certificates with IPv4 addresses.
- Apps can open PalmTLS without providing a seed. A Modern TLS session uses
  an app-provisioned seed when the caller omits the random-source flags.
  The session reports randomness unavailable if the seed is missing.
  Experimental stylus randomness still requires an explicit flag.
- TLS Tester can collect a stylus seed on supported handhelds and use it for
  HTTPS tests and downloads.
- ARM builds accelerate AES-256-GCM.
- The HTTP component adds reusable GET and POST request helpers, with
  keep-alive and opt-in gzip response handling.

Install exactly one library PRC. Applications using Modern TLS on ARM
devices should install `PalmTLSArm-Browser.prc`. TLS Tester is optional.
