PalmTLS 0.1.4 substantially reduces ARM TLS 1.3 handshake time while retaining one ARM PRC per protocol profile and support for older Palm ARM devices.

## Speed improvements since 0.1.3

| TLS 1.3 connection | 0.1.3 | 0.1.4 | Time reduction |
| --- | ---: | ---: | ---: |
| Cold full handshake, including engine/trust setup | 1,510 ms | 570 ms | 62% (2.65× faster) |
| Warm full handshake | 1,320 ms | 350 ms | 73% (3.77× faster) |
| Resumed handshake | 580 ms | 170 ms | 71% (3.41× faster) |

These are medians from two runs of five samples per case on cp-uarm at 100 MIPS, using the published 0.1.3 binary and the exact CI-built 0.1.4 release package. Both negotiate TLS_CHACHA20_POLY1305_SHA256, verify the same localhost certificate against eight trust anchors, and disable profiling. The external timer includes the complete SessionOpen/Handshake path; DNS/TCP setup and subsequent application I/O are excluded. Both versions were built with the same pinned CI toolchain image. These are emulator results, not physical-device or Internet latency promises. [Raw measurements and methodology](https://github.com/palmsnipe/palm-tls/tree/main/library/bench/baselines/2026-11-01-release-013-014).

The [benchmark evidence ZIP](https://github.com/palmsnipe/palm-tls/releases/download/v0.1.4/PalmTLS-0.1.4-benchmarks.zip) includes raw results, server confirmation, artifact hashes and the measurement method.

## Changes

- Share an ARMv4T native image across older TI925/ARM925T and newer ARM926/XScale devices, with qualification and 68K fallback. No CPU-specific PRCs are required.
- Accelerate GHASH, P-256 inversion, ECDSA order arithmetic, hex import, double-scalar verification, ECDHE shared-secret multiplication, and public-key validation. Preserve validation checks and private-scalar table selection protections.
- Reuse TLS contexts and identical trust stores for repeated connections. Keep hostname, verification mode and exact trust bytes in the reuse decision; retain explicit purge/cancel behavior.
- Reduce cold relocation and public CA PEM decoding overhead while retaining private-key decoder behavior.
- Add opt-in verification, handshake, ECDHE, loader and trust profiling with backward-compatible result sizes.
- Update pinned wolfSSL from 5.9.2 to 5.9.4.
- Retain 0.1.3's native ChaCha20-Poly1305, cipher preference, record authentication and copied-key erasure. Thanks to [OPerepadia](https://github.com/OPerepadia) for [the original contribution](https://github.com/palmsnipe/palm-tls/pull/1).

## Installation and validation

Install exactly one library PRC appropriate for the device and desired protocol profile. `PalmTLSArm.prc` is the full ARM package; `Modern` and `TLS13` packages omit older protocol engines. TLS Tester is optional. The ZIP includes binaries, the public header, documentation, licenses and SHA-256 checksums.

All six library packages pass the build/packaging checks, host crypto oracles and API regressions. The same extracted native image passes independent crypto oracles on TI925T and PXA270 CPU models, including ChaCha authentication/tampering and unaligned buffers. Real PRCs were installed and exercised in private emulator sessions with server-confirmed full and resumed TLS 1.3 connections.
