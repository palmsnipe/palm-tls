PalmTLS 0.1.5

## Changes

- The TLS 1.3 profile supports certificate pinning, ALPN and Ed25519 client
  identities for applications that authenticate both peers.
- Applications can opt into experimental stylus seeding on the Tungsten E2.
  Users can draw continuously while the application collects pen timing and
  raw digitizer samples. The entropy available on physical E2 hardware still
  needs to be measured.
- The ARM build accelerates Ed25519 arithmetic, and TLS reads use less
  buffering and copying.

Install exactly one library PRC for your device and protocol profile. For
applications that use pinned TLS 1.3 client authentication on an ARM Palm,
install `PalmTLSArm-TLS13.prc`. TLS Tester is optional.
