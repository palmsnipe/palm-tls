PalmTLS 0.1.12

## Changes since 0.1.11

- ARM TLS 1.3 opens full connections faster with improvements to P-256
  operations and certificate trust setup. Resumed connections use native
  SHA-256 key derivation for short TLS 1.3 inputs.
- The shared 68K and ARM loader groups pointer fixups by target bank at
  build time. At startup it relocates each read-only engine segment in one
  temporary buffer, writes the segment to Palm storage, and frees the buffer
  before the handshake.
- On the Tungsten E2 and Palm TX emulators, grouping the fixups cut median
  relocation time from 20 to 10 ms compared with the preceding storage-backed
  development build. Both builds used the same 63,052-byte peak relocation
  buffer for the ARM TLS 1.3 engine and left the same free heap with a
  session open. [XScale timing and heap measurements](https://github.com/palmsnipe/palm-tls/tree/v0.1.12/library/bench/baselines/2026-11-20-arm-xscale-relocation)

Install one library PRC for your device and protocol profile. Choose 68K for
DragonBall handhelds or ARM for supported ARM handhelds. Full, Modern, and
TLS 1.3 profiles are available for both. TLS Tester is optional.
