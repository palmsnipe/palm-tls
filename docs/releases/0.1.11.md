PalmTLS 0.1.11

## Changes since 0.1.10

- The 68K TLS 1.3 client prefers native X25519 key exchange and supports
  P-256 when requested by the server.
- Faster 68K P-256 arithmetic speeds up key generation, key agreement
  and signature verification.
- The 68K TLS 1.3 engine caches successful ECDSA/SHA-256 certificate
  signature checks within each reusable trust context. Each full handshake
  still validates the certificate path and hostname and verifies the live
  `CertificateVerify` proof.
- The standard ARM TLS 1.3 engine supports RSA-4096 and P-384/SHA-384
  certificate chains.
- An open library preserves sessions across foreground app switches.
  Cooperative TLS I/O leaves the display and auto-off timer under app control.

Install one library PRC for your device and protocol profile. Choose the 68K
build for DragonBall devices or the ARM build for supported ARM handhelds.
Full, Modern and TLS 1.3 profiles are available for each architecture.
TLS Tester is optional.

## 68K handshake performance

The published v0.1.10 PRC and the development build at commit `c8c42ba`
were tested on the same CloudpilotEmu Palm m515 session with the same
certificate, eight-root trust bundle and AES-128-GCM cipher. v0.1.10
negotiated P-256 and the development build negotiated X25519. Results are
medians of five full handshakes per case and exclude TCP setup and engine load.

| CPU speed | Full handshake | v0.1.10 | Development build | Time reduction |
| --- | --- | ---: | ---: | ---: |
| Stock | Cold | 36.470 s | 12.060 s | 66.9% |
| Stock | Warm | 36.280 s | 8.460 s | 76.7% |
| 16× | Cold | 2.280 s | 750 ms | 67.1% |
| 16× | Warm | 2.260 s | 530 ms | 76.5% |
