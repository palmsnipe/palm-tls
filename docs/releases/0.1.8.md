PalmTLS 0.1.8

## Changes since 0.1.6

- ARM builds verify P-256 signatures in projective coordinates and accelerate
  P-256 key generation and shared-secret computation. The generator path also
  uses less stack space.
- The ARM Browser profile adds P-384, SHA-384, RSA-4096, and IPv4 certificate
  address support for TLS 1.2 and 1.3.
- Applications can supply their own seed for Modern TLS. PalmTLS can be opened
  without a seed. If an app requests a Modern TLS handshake with the default
  random source and has supplied no seed, the handshake reports randomness
  unavailable. Experimental stylus randomness is opt-in, and TLS Tester can
  collect a stylus seed on supported devices.
- ARM builds accelerate AES-256-GCM. The HTTP component adds reusable GET and
  POST helpers with keep-alive and opt-in gzip responses.

Install exactly one library PRC for your device and protocol profile.
`PalmTLSArm-Browser.prc` provides Modern TLS on ARM devices. TLS Tester is optional.
